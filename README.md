# nidhi_aritistry

Website for **Nidhi Artistry**, a photography and film studio in Krishnapuram, Alappuzha: weddings, newborn and maternity, commercial ads, podcasts and events.

Built with React, Vite, GSAP (ScrollTrigger) and Lenis smooth scrolling.

## Run locally

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production files in dist/
```

## Editing content

Contact details, services, gallery photos, stats and studio rentals live in `src/data.js`.
Each page section is a component in `src/components/`.
